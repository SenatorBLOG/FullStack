
### Б. Способ 1: Использование Vite (Быстрый и современный старт)

Это самый быстрый и чистый способ запустить проект.

1.  **Команда для создания проекта:**
    Откройте терминал в папке, где вы хотите создать проект, и выполните:

    ```bash
    npm create vite@latest app.tsx on request
    ```

2.  **Ответы на вопросы:**
    Вам будут заданы вопросы. **Обязательно выберите React:**

      * `Project name:` (введите имя, например, `my-react-app`)
      * `Select a framework:` $\rightarrow$ **`React`**
      * `Select a variant:` $\rightarrow$ **`JavaScript`** (или `TypeScript`, если вы хотите строгое типизирование)

3.  **Установка зависимостей:**
    Перейдите в созданную папку и установите все необходимые библиотеки:

    cd my-react-app
    npm install

	npm install react-icons

4.  **Запуск проекта:**
    Эта команда запустит локальный сервер для разработки:
    npm run dev


    Проект откроется в браузере (обычно `http://localhost:5173`).

### В. Способ 2: Использование Next.js (Для полноценных приложений/веб-сайтов)

Next.js — это фреймворк, который является надстройкой над React и добавляет маршрутизацию, оптимизацию и рендеринг на сервере.

1.  **Команда для создания проекта:**

    ```bash
    npx create-next-app@latest
    ```

2.  **Ответы на вопросы (Пример):**

      * `What is your project named?` $\rightarrow$ `my-next-app`
      * `Would you like to use TypeScript?` $\rightarrow$ **`No`** (для начала)
      * `Would you like to use Tailwind CSS?` $\rightarrow$ **`No`** (для начала)
      * `Use App Router (recommended)?` $\rightarrow$ **`Yes`**

3.  **Запуск проекта:**
    Перейдите в папку и запустите сервер разработки:

    cd my-next-app
    npm run dev


    Проект откроется в браузере (обычно `http://localhost:3000`).

-----

## 3\. Где писать код (Важно\!)

В любом из этих проектов:

1.  **Всегда работайте внутри папки `src/` (Vite, CRA) или внутри папки `app/` (Next.js).**
2.  Файлы, в которых вы описываете интерфейс, будут иметь расширение `.js` или **`.jsx`** (для файлов, которые явно содержат JSX-синтаксис).
3.  Начните с редактирования главного компонента (например, `App.jsx` или `page.js` в Next.js). **Пишите там JSX**.

**Пример JSX в файле `App.jsx`:**

```javascript
// Это JavaScript
import React from 'react'; 
import './App.css'; 

function App() {
  const title = "Мой первый React-проект!"; // Это чистый JS

  // Всё, что внутри return(), это JSX
  return (
    <div className="App">
      <h1>{title}</h1> 
      <p>Теперь я понимаю разницу между JS и JSX.</p>
    </div>
  );
}

export default App;
```
